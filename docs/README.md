# Guides for modders

How the main program (`SLUS_205.15`) is put together, for people who want to read or change it.

- [CODE-MAP.md](CODE-MAP.md): which file holds which system, and the conventions the code uses.
- [DUEL.md](DUEL.md): how a duel is set up and runs, and where its state lives.
- [DATA.md](DATA.md): where card, deck, duelist, map, model and texture data lives.
- [SAVE.md](SAVE.md): the layout of the save profiles.
- [NAMING.md](NAMING.md): how names are chosen (and how the original Japanese names are kept).
- [../CONTRIBUTING.md](../CONTRIBUTING.md): how to propose names and fixes without changing the build.
